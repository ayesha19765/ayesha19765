## Featured Projects

### [ThreadVault — Concurrent Incremental Backup Engine](https://github.com/ayesha19765/ThreadVault)

**Java 21 • Concurrency • SHA-256 • Compression • PostgreSQL • Docker**

A backup engine designed around a producer-consumer architecture.

It supports:

* Concurrent backup workers
* Incremental backups
* Content-based deduplication
* SHA-256 hashing
* Compression
* Metadata indexing
* Atomic file writes
* Restore operations
* Backup scheduling
* Live progress updates
* Security protections such as restore path validation

The project was built with a focus on **concurrency, data integrity, failure handling, and storage efficiency**.

**Why I built it:** to understand what happens when a seemingly simple backup application has to deal with concurrency, duplicate data, partial failures, storage efficiency, and safe recovery.

### [ResolveHub — Backend Issue Resolution Platform](https://github.com/ayesha19765/ResolveHub)

**Java 21 • Spring Boot • PostgreSQL • JPA/Hibernate • Spring Security • Docker**

A backend-focused issue and ticket management platform designed to explore production-style backend engineering.

Highlights include:

* REST API design
* Role-based access control
* DTO-based API boundaries
* Jakarta validation
* Transaction management
* Dynamic filtering with JPA Specifications
* Database-level pagination
* Whitelist-based sorting
* PostgreSQL indexing
* N+1 query prevention
* Audit logging
* Unit, integration, repository, and security testing

The main goal of the project was to understand **how a backend evolves beyond basic CRUD into something maintainable and reliable**.
